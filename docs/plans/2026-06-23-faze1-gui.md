# Plán implementace — Tectora Fáze 1: GUI (PySide6 podle designu)

> Verze 1.0 · 2026-06-23 · větev `feat/faze1-reconcile` (nebo nová `feat/faze1-gui`).
> **Vizuální zdroj pravdy:** `docs/design/Tectora.dc.html` + `docs/design/screenshots/`.
> Backend (core/application/io/cli, 80 testů) je hotový — GUI je **tenká vrstva** nad
> už otestovanými use-casy. **Nepřepisovat backend.**

## Cíl

Postavit desktopové GUI přesně podle designu: **úvodní stránka** (knihovna zakázek)
a **editor** (kreslicí plátno + parametry + výsledky + 2D/3D). Plně offline, bez
loginu. Stávající staré **parametrické `gui/`** (form-based) se **nahradí**.

## Přístup k verifikaci (GUI ≠ čisté TDD)

GUI je vizuální a interaktivní — neověřuje se jen unit testy. Každý task ověř:
1. **Spustí se**: `python -m tectora.gui.main` naběhne bez chyby (smoke).
2. **Vizuální shoda**: porovnej se screenshotem v `docs/design/screenshots/` (layout,
   barvy, rozestupy).
3. **Smoke/logika testy**: kde jde logika oddělit (mapování modelu na kreslení,
   i18n katalog, převody souřadnic), napiš pytest test bez Qt eventloopu.
4. Backend testy (80) musí zůstat zelené.

Logika patří do `core`/`application` (otestováno); GUI jen volá use-casy a kreslí.

## Architektura GUI (`src/tectora/gui/`)

```
gui/
  main.py          # entry point: QApplication + MainWindow
  app_window.py    # MainWindow se QStackedWidget: HomeView ↔ EditorView, navigace
  theme.py         # tokeny (COL, paleta) + globální QSS, font Inter; nahrazuje starý style.py
  i18n.py          # katalog cs/sk/en + tr(key, lang); žádné natvrdo stringy
  home/
    home_view.py     # top bar (logo, hledat, jazyk) + "Nová zakázka" + welcome + grid + empty
    project_card.py  # karta zakázky: mini náhled (QPainter), název, meta, badge plochy, ⋮ menu
  editor/
    editor_view.py   # top bar (Zpět/název/menu/jazyk) + toolbar + canvas + right panel + status
    canvas_2d.py     # QWidget+QPainter: mřížka, snap, kreslení/úprava polygonu, typ hrany, osnova, legenda
    view_3d.py       # 3D náhled (rework stávajícího painter-based), tmavé plátno
    right_panel.py   # ZAKÁZKA (název, poloha, poznámka) + PARAMETRY (sklon, typ) + VÝSLEDKY
    location_field.py# našeptávač: QLineEdit + dropdown, NominatimGeocoder ve vlákně
```

Napojení na backend (vše už existuje):
`SqliteProjectLibrary`/`NominatimGeocoder` (io) · `uc.calculate_project/save_entry/
list_entries/load_entry/update_entry/delete_entry/suggest_location` (application) ·
`Project`/`Footprint`/`Location` (model).

## Task G0 — Theme, i18n kostra, app shell

**Files:** `gui/theme.py`, `gui/i18n.py`, `gui/app_window.py`, `gui/main.py`, `tests/gui/test_i18n.py`.

1. `tests/gui/test_i18n.py` (logika bez Qt):
   ```python
   from tectora.gui.i18n import tr, LANGS

   def test_langs_cs_sk_en():
       assert set(LANGS) == {"cs", "sk", "en"}

   def test_tr_returns_localized_and_falls_back():
       assert tr("new", "cs") == "Nová zakázka"
       assert tr("new", "en") == "New project"
       assert tr("nonexistent_key", "cs") == "nonexistent_key"  # fallback = klíč
   ```
2. `gui/i18n.py`: `LANGS = ("cs", "sk", "en")`; dict katalog `CATALOG[lang][key]`;
   `def tr(key, lang) -> str` (fallback na klíč). Naplň klíče ze screenshotů: `new`,
   `newSub`, `search`, `welcomeTitle`, `welcomeSub`, `myProjects`, `emptyTitle`,
   `emptyHint`, `back`, `draw`, `editPoints`, `eaveGable`, `pitch`, `calc`, `legend`,
   `ridge`, `hip`, `valley`, `eave`, `name`, `location`, `note`, `roofType`, `results`,
   `area`, `ridgeLen`, `hips`, `valleys`, `eavePerim`, `rakeL`, `rakeR`, `save`,
   `exportXls`, `delete`, `reset`, menu `file/edit/view/help`, atd.
3. `gui/theme.py`: `COL = {"ridge":"#e11d48","hip":"#9333ea","valley":"#0d9488","eave":"#2563eb","gable":"#ea580c"}`;
   paleta konstanty (ACCENT, BG, CARD, BORDER, TEXT, MUTED…); `GLOBAL_QSS` string
   (font Inter, pozadí #eef0f2, styly tlačítek/inputů/karet dle tokenů); `def apply_theme(app)`.
4. `gui/app_window.py`: `MainWindow(QMainWindow)` s `QStackedWidget` (index 0 = HomeView,
   1 = EditorView). Metody `open_home()`, `open_editor(project, entry_id=None)`. Drží
   aktuální jazyk; po přepnutí překreslí texty. Drží instanci `SqliteProjectLibrary(default_db_path())`.
5. `gui/main.py`: `def main(): app=QApplication; theme.apply_theme(app); w=MainWindow(); w.show(); sys.exit(app.exec())`.
   (Zachovej entry point `tectora-gui = "tectora.gui.main:main"`.)
6. Ověř: `python -m pytest tests/gui/test_i18n.py -q`; `python -m tectora.gui.main` naběhne
   (prázdné okno / home). Commit.

## Pozn. k závislostem

GUI vyžaduje extra `[gui]` (PySide6, pyvista, pyvistaqt) — `pip install -e ".[gui,dev]"`.
Stávající `view_3d.py` je painter-based (bez PyVista) — rework může PyVista využít, nebo
zůstat u QPainter (jednodušší, bez nativních závislostí). Rozhodnout v G7.
