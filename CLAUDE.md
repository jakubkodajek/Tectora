## Claude Code specifics

- Subagents live in `.claude/agents/`, skills in `.claude/skills/`. They are
  the source of truth; the Codex and Copilot copies (`.codex/agents/`,
  `.github/agents/`, `.agents/skills/`) are generated by
  `python3 scripts/sync_agents.py`. Run it after editing any agent or skill;
  CI fails when the copies are stale.
- Build a feature with `tectora-feature`, review with `tectora-review`, hunt
  bugs with `tectora-bug-hunt`, test a change with `tectora-test`, record a
  decision with `tectora-adr`, and end a session with `tectora-handoff`.
- Subagents start with an empty context: when you delegate, pass the slug,
  the files, the acceptance criteria and the DACAD case names explicitly.
- Hooks in `.claude/settings.json` block destructive shell commands, edits of
  secrets, lockfiles, generated agent files and DACAD material. If a hook
  blocks you, do not work around it; ask the human.
- At session start read the last entries of `memory/progress.md`, and
  `memory/decisions.md` before changing anything structural.
